# Changelog

## 0.1.0 - 2026-08-31

- Initial EspScreenOS platform repository
- Six generated ESP32 and ESP32-S3 board profiles
- LVGL shell, display/touch/storage/audio/power HAL, diagnostics, settings, assets, and network provisioning
- Fixed-capacity application/service/event/resource framework
- COBS/CRC framed protocol and RPC router
- Host tests, board validation, firmware CI matrix, and hardware qualification handbook
